# 005 — Phases 0–5 (before spec-kit)

Phases 0–5 were planned and built before the project adopted spec-kit, so they have no
`spec.md`/`plan.md`/`tasks.md` here. This folder exists so feature numbering continues from `006`.

Where to find what they delivered:

- **Roadmap and demos**: [`PLAN.md`](../../PLAN.md), Phase 0 to Phase 5
- **Design, invariants and decisions**: [`docs/architecture.md`](../../docs/architecture.md)
  (map), [`docs/design/`](../../docs/design/) (per-area detail and the "Deviations from the
  Phase N plan" sections) and [`docs/adr.md`](../../docs/adr.md) (ADR-001 to ADR-048 and the
  decisions they cite, D-numbers up to D128)
- **Setup and operations**: [`README.md`](../../README.md), [`infra/README.md`](../../infra/README.md)

Do not add specs to this folder. Changes to behaviour from these phases get a new feature folder.
