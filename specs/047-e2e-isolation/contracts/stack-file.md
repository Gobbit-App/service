# Contract: `e2e/.stack/stack.json`

Generated by the runner, gitignored, deleted at teardown. The only way test code learns where the stack is.
Read by `e2e/lib/stack.ts`, which validates the shape and throws "no stack: run `pnpm test:e2e`" if the file
is missing (so `playwright test` run by hand without a stack fails clearly).

```json
{
  "project": "gobbit-e2e-m3k2x9a1-q7z4",
  "webUrl": "http://127.0.0.1:18080",
  "apiUrl": "http://127.0.0.1:18080/api",
  "mailboxUrl": "http://127.0.0.1:18025",
  "startedAt": "2026-11-18T10:00:00.000Z"
}
```

| Field | Rule |
|-------|------|
| `project` | Compose project name; matches `^gobbit-e2e-[a-z0-9]+-[a-z0-9]{4}$` |
| `webUrl` | web origin (Caddy): app, `/welcome`, `/version.json`; no trailing slash |
| `apiUrl` | `webUrl` + `/api`; the origin Playwright uses for API requests; the API's own `API_URL` equals it |
| `mailboxUrl` | Mailpit HTTP origin (REST `/api/v1/…`) |
| `startedAt` | ISO time; informational |

`e2e/lib/stack.ts` exports `stack` (the parsed object, loaded once per process) and helpers `webUrl(path)`
and `apiPath(path)` (relative path, no leading slash, as the existing specs use, D46).
